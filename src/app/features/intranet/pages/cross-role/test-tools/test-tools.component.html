Simulación de asistencia CrossChex

Dispara una marcación simulada (sin CrossChex real) para una persona de prueba y verificá el correo de confirmación en la bandeja de correos.

Creación masiva — Salones

Generá salones de prueba sintéticos con un click, o importá un lote desde archivo.

Creación masiva — Cursos

Generá cursos de prueba sintéticos con un click, o importá un lote desde archivo.

Creación masiva — Usuarios

Generá usuarios de prueba sintéticos de cualquier rol (excepto Estudiante, que tiene su propio import) con un click, o importá un lote desde archivo con roles mixtos.

Creación masiva — Matrículas

Generá matrículas de prueba sintéticas con un click, o importá un lote desde archivo (vincula Estudiante↔Salón existentes).

Creación masiva — Calificaciones

Generá notas de prueba sintéticas con un click, o importá un lote desde archivo (contra una evaluación existente).
